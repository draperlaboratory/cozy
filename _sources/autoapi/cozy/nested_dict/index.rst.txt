.. py:class:: NestedDict(data: dict[str | int, A | dict])

   Bases: :py:obj:`Generic`\ [\ :py:obj:`A`\ ]


   A nested dict is an arbitrarily nested Python dict holding values on the leaves. The keys of the dictionaries    must be str or int values. Note that NestedDict objects should not contain NestedDict objects within their    data dictionary. In other words, NestedDict is a wrapper for a dict, and does not nest inside itself.
